# 歌曲特征

歌曲会先按标题和专辑名生成低置信度的风格线索。能量与节奏优先来自本地音频分析；尚未分析的歌曲仍可正常参与候选，只是这些字段保持未知，选歌不会因为未知而排除它。

运行 `npm run audio:profile` 可抽样分析收藏歌单，默认最多分析 50 首；可用 `npm run audio:profile -- --limit=100` 扩大样本。音频只下载到内存进行计算，磁盘只保存数值特征缓存，不保存音频文件或播放地址。分析按 50ms 窗口提取响度、起音密度、持续活动比例和动态起伏；四项在已分析样本的 P10–P90 范围内归一化后，按 30%、35%、25%、10% 合成能量值。节奏仍由 RMS 起音变化的自相关估算，不能替代专业音乐信息检索模型，尤其对半拍/倍拍和复杂节奏可能有误差。

为避免小样本歌曲因“已测量”而占优，只有当前时长候选池中至少 65% 的歌曲都具备能量与节奏特征时，选歌才启用音频特征；覆盖不足时，整个候选池仍按同一套元数据基线比较。默认 50 首用于先验证分析质量与成本，不会单独提高这些歌曲的排序。

缓存位于 `data/song-audio-features.json`，按歌曲元数据指纹复用。运行时只读取缓存，不会为生成路线临时下载或解码音频。
